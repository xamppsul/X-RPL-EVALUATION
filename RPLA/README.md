## 📈 Progres Pembelajaran HTML & CSS

| Materi                        | Persentase Pemahaman |
|--------------------------------|------------------------|
| Tag-tag dasar HTML             | ✅ Sudah dipahami       |
| Syntax dasar CSS               | ✅ Sudah dipahami       |
| **Total Capaian**              | **80%**                |

Pemahaman siswa terhadap materi dasar HTML dan CSS secara keseluruhan sudah berjalan dengan baik, dimulai dari tag-tag dasar HTML hingga syntax dasar CSS.

## 📝 Tugas Terakhir

**Materi**: Memahami syntax CSS lanjutan, khususnya pemanggilan selector:
- `#class_name` — selector berdasarkan **id**, dipanggil melalui atribut `<div id="">`
- `.class_name` — selector berdasarkan **class**, dipanggil melalui atribut `<div class="">`

Siswa diharapkan mampu membedakan dan menerapkan kedua jenis selector tersebut dalam menghubungkan elemen HTML dengan styling CSS.

## 🚀 Rencana Pembelajaran Selanjutnya

Jika seluruh siswa di kelas telah menyelesaikan tugas terakhir (selector CSS lanjutan), maka kelas akan langsung melanjutkan ke tahap berikutnya, yaitu:

1. **Belajar JavaScript** — pengenalan dasar bahasa pemrograman JavaScript
2. **Menghubungkan file HTML dengan JavaScript** — menggunakan tag `<script>` untuk mengintegrasikan logika JavaScript ke dalam struktur halaman web

### Alur Progres Belajar

```
HTML Dasar → CSS Dasar → CSS Lanjutan (Selector) → JavaScript Dasar → Integrasi HTML + JavaScript
     ✅            ✅              📍 (saat ini)              ⏭️                  ⏭️
```

## 📌 Catatan

- Data skor kuis dapat diperbarui setelah sesi berlangsung
- Tugas selector CSS lanjutan menjadi syarat sebelum lanjut ke materi JavaScript
- Progres pembelajaran ini bersifat dinamis dan dapat disesuaikan dengan kecepatan pemahaman siswa di kelas
