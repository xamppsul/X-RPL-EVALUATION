# Hasil Belajar & Tugas — Kelas RPL A, RPL B, RPL C

Dokumen ini merupakan panduan umum untuk mendokumentasikan hasil belajar siswa beserta daftar tugas yang diberikan di kelas Rekayasa Perangkat Lunak (RPL A, RPL B, dan RPL C).

## 📋 Deskripsi

Berkas ini mencatat perkembangan hasil belajar siswa dari sisi capaian materi maupun tugas-tugas yang telah/sedang diberikan per kelas. Digunakan sebagai acuan guru mapel/wali kelas dalam memantau progres siswa dan riwayat penugasan selama satu semester.

## 🎯 Tujuan

- Mendokumentasikan hasil belajar siswa per kelas secara rapi dan terstruktur
- Mencatat riwayat tugas yang diberikan, termasuk deadline dan status pengumpulan
- Memudahkan evaluasi capaian belajar antar kelas (RPL A, B, C)
- Menjadi bahan laporan ke wali murid maupun pihak sekolah

## 🔄 Alur Pendokumentasian

1. Guru mapel mencatat setiap tugas yang diberikan (judul, tanggal, deadline) ke dalam daftar tugas per kelas
2. Setelah tugas dikumpulkan, status pengumpulan diperbarui
3. Hasil belajar dicatat berdasarkan capaian siswa terhadap materi/kompetensi yang diajarkan
4. Wali kelas merekap hasil belajar dan status tugas secara berkala (mingguan/bulanan)
5. Rekap akhir semester dibandingkan antar kelas (RPL A, B, C) untuk melihat capaian angkatan

## 📌 Catatan

- Format tabel di atas bersifat **contoh umum**, dapat disesuaikan dengan kurikulum dan jenis tugas di masing-masing sekolah
- Disarankan menyimpan data dalam format spreadsheet (.xlsx/.csv) untuk memudahkan pengolahan dan rekap
- Update data dilakukan setiap kali ada tugas baru atau setelah nilai/hasil belajar diinput

## 🤝 Kontribusi

Jika dokumen ini digunakan bersama oleh beberapa guru/wali kelas:
- Gunakan format kolom yang konsisten antar kelas
- Informasikan perubahan format ke semua pihak terkait
- Lakukan backup data secara rutin
